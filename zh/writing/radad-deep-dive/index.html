为什么医疗报告生成需要角色非对称的双 Agent

不是让两个 Agent 重复回答，而是让它们承担不同临床风险：一个优先召回，一个优先控制误报。

#Multi-Agent#Medical AI#RAG

单次大模型推理常把两个不同目标揉在一起：既要尽可能发现异常，又不能把不确定线索写成确诊结论。在胸部 CT 报告中，这不是普通的文本质量问题，而是召回与精确之间的临床风险权衡。

对称辩论为什么不够

如果两个 Agent 拥有相同提示、相同目标和相同证据，它们很容易产生相关性很高的答案。表面上有“讨论”，实质上只是重复采样。RADAD 的核心不是增加 Agent 数量，而是设计角色差异：召回角色主动寻找可能遗漏的临床发现，审慎角色专门检查证据不足和过度推断。

共享证据锚点

系统先用 BiomedCLIP 编码 CT 图像，再从 FAISS 索引中检索视觉相似案例。两个 Agent 看到同一组案例，但按照不同风险偏好解释它们。这样，争论围绕可检查的证据展开，而不是围绕各自的语言直觉。

有限交互而非无限讨论

系统只使用 3 次图像调用和 4 步纯文本交互。限制轮数迫使协议把信息集中在“发现—质疑—修订”上，也让推理成本能够被测量。

结果如何理解

BLEU-4 从 0.122 提升到 0.260，Macro-F1 从 0.368 提升到 0.437。指标提升只是结果，真正可迁移的部分是：先识别任务中的冲突目标，再为不同目标设计角色、证据和终止条件。
