Agent 应用开发贡献者 · 2026.05

超聚变企业级 Agent 业务场景配置系统

让通用 Skill Template 能够理解具体业务场景、执行策略与用户偏好，并在运行时形成个性化计划。

自然语言 → 结构化 ProfileProfile 优先级高于 Template校企合作项目

业务约束

通用 Skill Template 能描述能力，但不能完整表达企业用户的场景、流程与策略偏好；如果每次都重新写 Skill，维护成本和一致性风险都会上升。

我的动作

  • 参与 Profile 自动生成模块：从自然语言提取适用场景、流程概览、执行策略等维度。
  • 生成结构化 Markdown Profile，使配置可读、可审查、可版本化。
  • 参与运行时合并理解机制，按“Profile 优先级高于 Template”形成任务计划。

价值

把“用户个性化需求”从临时 Prompt 提升为可维护的场景配置层，为通用 Agent Skill 的企业级复用提供基础。
