中医知识图谱全链路构建系统

把 5 本中医教材中的疾病、辨证、方药知识转化为可查询、可校验、可持续迭代的知识底座。

33,214 个实体37,766 条关系药茶子图 3,420+ 条关系

业务约束

传统中医教材知识分散在非结构化文本中，直接依赖单次 LLM 抽取会产生实体漂移、关系冲突和不可追踪的错误。

我的动作

  • 构建 Embedding 相似检索、Few-shot 例库与 LLM 抽取流水线。
  • 设计自动评分机制：低分结果重抽取，高分结果入库并反哺例库。
  • 实现 JSON / Excel 标准化导入、实体归一、冲突检测和关系可靠性校验。

结果

最终图谱包含 33,214 个实体和 37,766 条关系，覆盖疾病、辨证、方药全链路，并形成可支撑后续 RAG 与中医大模型评测的数据基础。
